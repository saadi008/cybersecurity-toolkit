# 🔐 Cybersecurity Toolkit (Python)

A multi-functional cybersecurity toolkit built using Python, featuring real-time packet sniffing, port scanning, and DNS lookup with a graphical user interface.

---

## 🚀 Features

- 📡 Packet Sniffer
  - Captures real-time network traffic
  - Displays IP, TCP, and UDP details

- 🔍 Port Scanner
  - Scans target IP for open ports (1–1024)

- 🌐 DNS Lookup
  - Resolves domain names to IP addresses

---

## 🛠️ Technologies Used

- Python
- Scapy
- Tkinter
- Socket Programming
- Threading
